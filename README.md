# Yield-Curve-CDS-Bootstrapping
This repository provides tools for fixed-income pricing and credit risk modeling, featuring an interest rate curve bootstrapper that extracts discount factors and zero-rates from Depos, STIR futures, and Swap rates. Additionally, it includes algorithms for Credit Default Swap (CDS) hazard rate bootstrapping (comparing exact methodologies with Jarrow-Turnbull approximations), asset swap spread evaluations, and Monte Carlo simulations for default time distributions.

### Project context: 
Assignment for the Financial Engineering course @ Politecnico di Milano
